# SupDance Canvas Codex plugin

The supplied SupDance logo is stored at [`assets/logo.png`](assets/logo.png).

Install the versioned local Agent package first, then add this repository as
a Codex marketplace and install `supdance-canvas@supdance-local`. Start a new
Codex task so its `supdance-canvas` MCP and skills are loaded. The detailed
installation and connection checks are in the repository README.
